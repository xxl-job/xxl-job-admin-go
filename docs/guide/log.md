# 调度日志

「调度日志」记录每次任务触发的全过程。

## 历史日志

支持按 `job_id`、`status`（success / fail）筛选。每条记录含：

- **触发信息**：触发时间、触发结果、被调度的机器地址
- **执行信息**：handle_code（200=成功）、handle_msg、执行耗时
- **告警状态**：是否已触发告警

## 实时日志

点击单条记录的「查看日志」，通过 WebSocket 实时接收执行过程中的日志输出：

- 执行器在 handler 内调用 `Log()` 上报的分段日志
- 连接走 `/api/logs/:id/stream?token=xxx`（token 经 query，浏览器 WS 无法自定义 Header）

实时日志仅在任务执行期间有效；执行结束后转为历史记录留存。

## 失败排查

1. **触发失败**：多为「无在线执行器」→ 检查执行器是否注册、心跳是否正常
2. **执行失败**：handle_code ≠ 200 → 进入实时日志查看 handler 报错堆栈
3. **超时**：调大任务「超时时间」或优化 handler 性能
4. **自动兜底**：配置「失败重试次数」可在偶发失败时自动重试
