# 用户与权限

「用户管理」用于管理可登录调度中心的账号及其执行器权限。

## 角色

| role | 含义 |
|---|---|
| 1 | 管理员（super_admin，全部权限） |
| 0 | 普通用户 |

## 执行器权限

普通用户只能操作授权的执行器分组。`permission` 字段以逗号分隔 `app_name`：

- 空：无任何执行器权限
- `demo-app,billing`：可操作这两个分组下的任务与日志

管理员（role=1）忽略 permission，拥有全部权限。

## 操作

| 操作 | 说明 |
|---|---|
| 新建用户 | 设用户名 / 密码（bcrypt 加密）/ 角色 |
| 编辑 | 修改信息；密码留空则不修改 |
| 删除 | 移除账号（内置 admin id=1 禁删） |

::: warning
内置 admin（id=1）不可删除。生产环境请及时修改其默认密码 `123456`。
:::

## 审计日志

「系统管理 → 操作日志」记录所有写操作的 actor / action / target，便于安全审计与问题追溯。
