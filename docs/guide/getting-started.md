# 快速开始

本篇带你在几分钟内完成首次登录、注册执行器并调度第一个任务。

## 1. 登录系统

浏览器打开调度中心地址（本地开发默认 `http://localhost:5173`，生产为你的域名）。

首次登录使用内置管理员账号：

| 项 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |

::: warning
首次登录后请立即在「用户管理」修改默认密码。
:::

## 2. 查看仪表盘

登录后进入仪表盘，可见：

- **统计卡片**：任务总数、运行中、今日执行次数、成功率
- **趋势图表**：近期调度量
- **快捷入口**：新建任务、查看日志等

详见 [仪表盘](./dashboard)。

## 3. 注册执行器

任务必须调度到「执行器分组」上。先创建一个分组：

1. 进入「执行器管理」→「新建」
2. 填写 `app_name`（执行器唯一标识，如 `demo-app`）与标题
3. 地址类型选「自动注册」（执行器启动后自动上报地址）

执行器侧需用相同 `app_name` 连接调度中心（gRPC `:9090`），开发细节见开发者文档 [执行器开发](../executor-dev)。

## 4. 创建第一个任务

1. 进入「任务管理」→「新建」
2. 选择上一步的执行器分组
3. 填写：
   - **Handler**：执行器注册的处理函数名（如 `demoJob`）
   - **调度类型**：CRON / 固定频率 / 固定延时
   - **调度配置**：如 CRON `*/5 * * * * ?`（每 5 秒）
   - **参数**：传给 handler 的字符串
4. 保存后点「启动」

## 5. 查看调度结果

进入「调度日志」，可见每次触发的：

- 触发时间、触发结果
- 执行结果（成功 / 失败）
- 实时日志（点「查看日志」走 WebSocket 实时流）

---

至此你已完成首个任务的完整调度闭环。后续章节详细介绍各项功能。
